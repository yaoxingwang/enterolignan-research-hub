C

官方权重覆盖及能解决的问题

使用regular文件sharewX_rel9-0-0_gv_longitudinal_weights_w8w9.dta中的cliw_i。panel_resp=1表示各指定轮均有个人主访谈；不等同于量表完整、分析入选或存活标志。权重文件40,170人，panel_resp=1有38,616人，其中375人仍无个人权重；正个人权重共38,241人。

原重访者中有1,067人（4.04%）未覆盖，全部来自荷兰（country=14），该国在regular 8→9纵向权重文件中没有记录。其余样本国家覆盖100%。本轮不以家庭、横断面、设计或Corona权重补缺；荷兰缺失的具体原因未获官方解释。

起始轮设计字段dw_w8/subsample/stratum1/stratum2/psu/ssu在全部40,170条匹配记录上与第8轮一致；分析者重建聚类也全部一致。官方权重子样本的weight-only Kish n=3,096.1，最大权重623,987.8；Kish值不是包含抽样聚类的完整有效样本量。

Release 9文档将8→9权重目标描述为2019年50岁及以上、存活至2021年的人口。官方权重处理其校准设定下的面板参与选择，不能自动消除额外的本人答题、饮食/量表完整病例选择及所有非随机流失。当前又限制55–110岁、基线筛查阴性，因此不直接代表全部目标人口。

主要调整：年龄及平方、性别、教育、伴侣同住、国家、基线访谈年/月、基线连续EURO-D、访谈间隔。扩展增加吸烟、适度活动、过去7天饮酒和慢病数分组。结局是第9轮EURO-D≥4；无法观察访间起病与缓解过程，不称总体抑郁发病率。

方法、资料与已完成检查

五个纵向模型使用加权Poisson与聚类稳健CR1协方差、t(G−1)区间。权重在样本内均值归一化。聚类为起始轮country+subsample+stratum1+psu；PSU缺失时退回家庭。未实现正式分层方差、FPC及完整设计自由度，所有区间都标为近似，官方权重并不自动补齐survey方差实现。

第8轮访谈年与月份存在完全共线时间列，pivoted QR仅删除冗余C(int_month)[T.10]，不改变模型列空间。五模型均满秩、收敛、协方差有限且对角线为正，估计方程最大绝对残差小于1e−4。不加权聚类协方差与statsmodels独立实现的最大差异为1.69e-15。

个人键唯一、一对一连接、国家/性别核对、原始重访样本复现、起始设计一致性、CRP/TRG截顶和all-waves状态审计均通过。EURO-D12项及官方总分/分类由复用代码逐轮核对。该数据核对不替代阈值的外部临床验证。

资料为下载包内《SHARE_release_guide_9-0-0.pdf》（physical pp16–17个人键与缺失码、pp40–48权重及目标、p57 EURO-D、pp86–87设计字段）及《SHARE wave 6 DBS Biomarker Cohort Profile Release Documentation 2-0-0.pdf》（pp3–10采集/检测及限制、pp16–18指标、pp21–22权重）。Release guide表7的8→9权重名与实际DTA不一致，实施使用已核实的cliw_i；原始PDF受原数据许可管理，不纳入汇总包。
